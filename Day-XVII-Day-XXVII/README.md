## 🚀 Day 17–27 — Tamil Nadu Assembly Election Analytics

### 🇮🇳 Tamil Nadu Assembly Election Analytics — 2021 vs 2026

Built an end-to-end election analytics project using Microsoft Fabric, SQL, PySpark, and Power BI.

**Focus:**
- Geographic Seat Distribution
- Constituency Winner Flips
- Margin of Victory
