# 🧩 Problems Solved

## 1️⃣ Risky Projects (Medium)

### Business Scenario

A company wants to identify projects that have exceeded their allocated budget after calculating the prorated salary cost of employees assigned to each project.

### SQL Concepts Used

- Multiple INNER JOINs
- CTE
- Aggregate Functions
- TIMESTAMPDIFF()
- CEILING()
- GROUP BY
- Filtering aggregated results

### Outcome

Successfully calculated prorated employee expenses and identified projects where total expenses exceeded the allocated budget.

---

## 2️⃣ Monthly Percentage Difference (Hard)

### Business Scenario

Calculate month-over-month revenue growth using transaction data.

### SQL Concepts Used

- CTE
- DATE_FORMAT()
- SUM()
- Window Function
- LAG()
- Percentage Calculation

### Outcome

Successfully calculated monthly revenue percentage changes using the previous month's revenue with the `LAG()` window function.

---

# 📖 Key Learnings

Today reinforced several important SQL concepts:

- Choosing the appropriate JOIN based on business requirements.
- Breaking complex problems into smaller steps using Common Table Expressions.
- Using Window Functions instead of self joins for previous-row calculations.
- Writing cleaner and more readable SQL queries.
- Thinking in terms of business logic rather than only SQL syntax.

# 💡 Reflection

Today was not about learning new tools—it was about strengthening one of the most important skills for every Data Analyst: SQL.

Every query completed today improved my confidence in translating business requirements into SQL solutions.
